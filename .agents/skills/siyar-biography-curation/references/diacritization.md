# التشكيل الكامل والإعراب في طبقة العرض

## الإلزام وطريقة القراءة

شكّل النص كاملًا: بنية الكلمات وأواخرها بحسب التركيب والوصل، وعناوين المصدر والعناوين التنظيمية المؤلفة. لا تختزل المهمة إلى الكلمات الملونة أو الملتبسة. لا تحتاج الواجهات الإدارية وأسباب الوكيل إلى تشكيل شامل، ولا يُعاد تشكيل المنشور ضمن تحديث المهارة.

اقرأ الخبر المتصل قبل ضبطه: من المتكلم؟ أين ينتهي القول ويعود التعليق؟ ما مرجع الضمير والعامل في الاسم أو الفعل؟ قد يجعل الضبط الفاعل مفعولًا أو المعلوم مجهولًا؛ لا تحكم من الكلمة المنفردة. راجع الأسماء والأنساب والكنى والإضافة والممنوع من الصرف و«ابن» و«أبو» في الجملة؛ اللون لا يثبت النطق أو الهوية.

احفظ أثر النفي والشرط والاستدراك والاستثناء والعطف، ولو فصلته صفحة أو علامة `#`. اضبط الأواخر على الوصل، دون تسكينها بسبب نهاية الفقرة. لا تصلح لفظًا أو وزن شعر بتبديل الحروف، ولا تضف ألفًا أو همزة أو توحد «ى/ي» أو تنقل حركة أصلية بحجة إملاء آخر. الحروف وحركات المصدر السابقة ثابتة، بما فيها الآيات والأحاديث والأدعية؛ التشكيل التحريري لا يوثق قراءة قرآنية أو يصحح متنًا.

كل كلمة تحتاج قرارًا بعد القراءة، حتى إن بدا ضبطها موجودًا. وجود حركة آليًا أو كثرة الحركات لا يثبت صحة الإعراب؛ حروف المد والألف الفارقة لا تحتاج حركة مصطنعة لإكمال عدد شكلي.

يرفض فاحص الحفظ كلمة عربية معلنة `complete` ليس فيها أي حركة أصلية أو مضافة؛ هذا يمنع الإغفال الكلي فقط ولا يثبت اكتمال ضبط كل حرف. يمكن إبقاء رموز التخريج مثل «ت، ق» `not_applicable` مع سبب يبين أنها رموز ببليوغرافية وليست كلمات منطوقة، دون تعميم الاستثناء على الكلمات العربية.

## الإضافات والالتباس

يسمح الملف بإضافة الحركات الثماني المعتادة `U+064B..U+0652` فقط: التنوينات الثلاثة والفتحة والضمة والكسرة والشدة والسكون. لا تضف تطويلًا أو علامة قرآنية أو تنسيق Unicode، ولا تحول الأصل إلى NFC/NFD للمطابقة. ترفض الإضافات المكررة أو المتعارضة أو الملحقة بصفحة أو مسافة أو رمز.

تتبع الإضافة حرف أساس أصليًا وتوضع بعد مجموعته الأصلية، مع حفظ ترتيب حركات المصدر. لا تحذف حركاته ثم تعيد توليدها. إذا تعذر حسم ضبط كلمة بعد التدقيق، أو بدا ضبط المصدر مناقضًا للسياق، سجل `uncertain` بسبب محدد وأبق الكلمة كاملة بلا إضافات جديدة. يسمح بنشر بقية الدفعة مع تنبيه وعدد المواضع المعلقة، ولا تسمى تلك المواضع مكتملة الضبط.

## ملف التأليف والتغطية

يصدر `export` ملف `diacritics.json` غير مكتمل. يحمل الإصدار `curation-diacritics-v1` ومعرّف الترجمة وبصمة المصدر وحدودها و`reviewer`، ثم:

- `insertions:[{at,base_start,marks}]`: موضع الإدراج `at` صفري العرض بوحدات Unicode بعد المجموعة الأصلية، و`base_start` موضع حرف الأساس، و`marks` الحركات المضافة وحدها. لا يتغير نطاق الشاهد بسببها.
- `words:[{start,end,status,reason?}]`: كل عنصر صادر مرة واحدة بنطاقه الأصلي. `complete` للكلمة التي راجعت ضبطها، و`uncertain` لتعذر الحسم مع سبب، و`not_applicable` للأرقام والألفاظ غير العربية أو رمز تخريج عربي كـ«ت، ق» بعد فحصه وتعليله، و`unexamined` حالة تصدير تمنع النشر. لا تستعمل عدم الانطباق لتجاوز كلمة عربية عادية.

يرفض الفاحص إعلان كلمة عربية مكتملة إذا لم تحمل أي حركة أصلية أو مضافة؛ هذا يمنع السهو الكامل فقط. وجود حركة واحدة لا يثبت تمام التشكيل أو صحة الإعراب، ولا يجيز تعليم بقية الكلمات تلقائيًا.

استخدم تقطيع `backend.diacritics.word_spans` المعتمد، ولا تعد علامات OpenITI كلمات أو تضيّع اللواصق والحركات. يمكن أن تثبت `derive_insertions(original,vocalized,offset)` أن النص المؤلف لا يضيف سوى الحركات؛ لا تتخذ الدالة قرارات الضبط. أصلح الفروق المرفوضة بدل تعديل المصدر. لا تعلم الكلمات جماعيًا `complete` قبل قراءة كل منها، ولا تجعل اكتمال التغطية دليلًا لغويًا.

## التدقيق والعرض والتقرير

يقرأ قارئ مستقل الضبط والإعراب والأسماء واتصال الفقرات، خصوصًا النفي والمجهول ومرجع الضمير ونسبة النقد. تُعاد التصحيحات إلى المؤلف، ثم تجمد بصمة تضم ملف التشكيل وملاحظات الفقرات. لا يوقع المؤلف باسم مدقق مستقل، ولا يصير تدقيق الوكيل اعتمادًا بشريًا.

اختبر خيار «إظهار الحركات المضافة» والنسخ المنسق، وبقاء حركات الأصل عند تعطيله. نسخة الأصل وشواهد البحث والموضوعات حرفية. يتبع تظليل حرف الأساس إضافاته، مع سلامة الألوان والتحقيق والحواشي والإحالات. افحص اتصال الحركات وعدم قصها مع تكبير الخط والجوال.

انشر أعداد الكلمات المدققة والمكتملة والملتبسة وغير المنطبقة، وأسباب الالتباس. فرّق بين تغطية الفاحص وصحة الاجتهاد اللغوي؛ لا تعرض نسبة التغطية بوصفها نسبة صحة التشكيل.
