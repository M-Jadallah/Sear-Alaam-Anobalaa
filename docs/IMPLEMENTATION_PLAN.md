# خطة التنفيذ المعتمدة: القارئ المنسق والبحث بالوصف

اعتمد المستخدم تنفيذ الخطة التالية بعد اختيار «محلي متوازن» و«اختيار المعنى أولًا».

## القارئ

- عرض منسق افتراضيًا مع تبديل محفوظ محليًا إلى الأصل الحرفي.
- طبقة OpenITI مستقلة: عناوين ### $ / $$ / |، فقرات #، استمرار ~~، وإخفاء ms الرقمية و</span> المعروفتين فقط؛ إبقاء الحروف والضبط والنجوم والأقواس والأرقام الأخرى.
- كل جزء معروض يحمل نطاق Unicode أصليًا؛ المسافات الافتراضية لتوصيل الأسطر لا تغير نطاقات المصدر.
- الصفحات إحالات صغيرة غير محققة طباعيًا، مع تمييز PageV00P000.
- نفس العارض للتراجم والأقسام والشواهد، والنسخ منسقًا مع المرجع أو خامًا.
- لا HTML قابل للتنفيذ، ولا تعديل للمصدر أو النصوص أو المراجعات.

## البحث

- وضع بالكلمات ووضع بالوصف. الوصف ينتج 1–3 بطاقات معنى قابلة لتعديل الوصف والمفاهيم والكلمات المطلوبة والمستبعدة، دون شواهد أو أعداد قبل الاختيار.
- تحليل محلي موجّه بالقواعد والمعجم، مع تصريح بحدود فهم النفي والبدائل والأسماء؛ لا نموذج محادثة ولا API مدفوعة.
- E5 multilingual-e5-small للتمثيل الدلالي وmmarco-mMiniLMv2-L12-H384-v1 لإعادة الترتيب؛ تثبيت مراجعاتهما وبصماتهما.
- نوافذ حتى 320 token وتداخل حتى64 داخل القسم نفسه، تجمع فقرات متجاورة ولا تقطع فقرة إلا إذا تجاوزت الحد؛ لا اقتطاع صامت.
-100مرشح لفظي و100دلالي؛ RRF k60؛ إزالة تكرار النوافذ المتداخلة دون دمج الأشخاص؛ إعادة ترتيب أفضل40؛ صفحات10. العدد عدد المرشحين المتاحين، لا جميع مواضع الكتاب.
- كل شاهد شريحة حرفية من الأصل ونطاق قابل للتحقق؛ سبب الترشيح منفصل عن الاقتباس. درجات الصلة ليست احتمالات صحة علمية. لا حفظ تلقائي لوسم أو هوية أو قصة.

## الواجهات والتشغيل

- واجهة reading-view للتراجم والأقسام ومقتطفات المصدر، مع كتل ورُزم نص ونطاقات.
- POST /api/search/interpret، POST /api/search/smart، GET /api/semantic/status؛ توافق البحث اللفظي وواجهات الأصل الحالية.
- بيانات الفهرس مشتقة وملفات متجهات محلية، دون خادم قاعدة متجهات.
- python -m backend.semantic prepare ينزل النماذج ويجهز فهرسًا قابلًا للاستئناف والنشر الذري. صلاحية الفهرس مرتبطة ببصمة المصدر وإصدار العارض والنماذج.
- CPU بأربعة خيوط وعامل استدلال منفصل واحد؛ تخزين مؤقت15دقيقة يبطل عند تغير الفهرس أو سجل المراجعة.
- بعد الإعداد يعمل دون إنترنت. عند نقص النماذج يبقى البحث اللفظي برسالة صريحة ولا يوصف بالدلالي.
- نسخة SQLite احتياطية قبل أي تغيير للمخطط؛ لا إعادة استيراد المصدر ولا حذف المراجعات.
