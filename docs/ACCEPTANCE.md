# معايير القبول واختبارات الجودة

## استيراد/مصدر
- [ ] إذا لم يوجد `data/source.mARkdown` لا يدّعي التطبيق وجود تراجم مفهرسة، ولا يختلق محتوى.
- [ ] إذا وضع المستخدم ملف النص، يمكن الاستيراد من أمر واضح أو واجهة، وتخزن بصمة SHA-256.
- [ ] تكرار الاستيراد نفسه لا يكرر التراجم أو المقاطع أو الموضوعات.
- [ ] تؤخذ عيّنات فعلية من بداية الملف ووسطه ونهايته لفحص البنية ومواقع الصفحات.
- [ ] لا يفقد النص أي علامة أو حرف في وضع القراءة الأصلية؛ مراجعة عينة حدود ترجمة بين ترجمتين.

## التراجم والأعلام
- [ ] عند الضغط على ترجمة يعرض النص الكامل من المصدر لا مجرد عنوانها أو ملخصًا آليًا.
- [ ] عند فتح شخصية تُعرض تراجمها الأصلية منفصلة عن «ذكرها في تراجم أخرى».
- [ ] الأسماء المتشابهة تتطلب اختيار هوية أو مراجعة ولا تُدمج تلقائيًا.
- [ ] يعرض تاريخ الوفاة فقط إذا ثبت من المصدر أو حقق يدويًا.

## الموضوعات والأخبار
- [ ] المعجم يتضمن 81 موضوعًا في 9 أبواب وتُعرض جميعها ولو لم توجد نتائج بعد.
- [ ] لكل موضوع نتيجة استشهاد نصية بمقطع، ولا تكفي مطابقة في عنوان الترجمة لتبرير كل نصها.
- [ ] نتيجة لفظية تميّز بوضوح أنها مرشحة حتى تُراجع.
- [ ] مثال مضاد لا يُصنف عشوائيًا؛ ظهور «النار» بمعنى نار حقيقية لا يكفي لتصنيف «الجنة والنار».
- [ ] القصة الواحدة قد ترتبط بعدة موضوعات والشخصية الواحدة قد تتكرر في عدة أخبار.
- [ ] كل شاهد يفتح الموضع ذاته داخل الترجمة الأصلية.

## البحث العربي والإحالات
- [ ] «الإخلاص» و«الاخلاص» تنتجان بحثًا معقولًا، بلا تغيير العرض الأصلي.
- [ ] فهرس FTS يعيد النص الكامل بتجزئة صفحات نتائج، بلا تحميل كل شيء للمتصفح.
- [ ] روابط المرجع تعرض علامة OpenITI الخام، ولا تسميها جزء/صفحة مطبوعين إلا بعد التحقق.
- [ ] اختبارات حدود العناوين والصفحات وحرفية الشواهد واختبارات API والواجهة تعمل.

## الأداء والجودة

- [ ] طبقة التشكيل الجديدة تضيف الحركات المسموح بها فقط، وإزالة إضافاتها المسجلة تعيد الأصل بكل حركاته وترتيبها.
- [ ] كل كلمة في الدفعة الجديدة مفحوصة، والملتبس معلل ومحفوظ على ضبط المصدر، والفقرات معللة بسياقها؛ لا تكفي مطابقة شكلية لإثبات الصحة اللغوية.
- [ ] التبديل والنسخ والتظليل والحواشي يعمل مع التشكيل، ولا تتغير الدفعات القديمة أو المراجعات أو فهارس الأصل.
- [ ] اختبار الاستيراد على ملف حقيقي أو إثبات أن هذا الاختبار متعذر بسبب غياب الملف.
- [ ] واجهة RTL واضحة على الجوال والكمبيوتر.
- [ ] تقرير QA يبين عدد التراجم والمواضع والنتائج المعلقة وأمثلة الإخفاقات المعروفة؛ لا يدّعي الشمول دون قياسه.
