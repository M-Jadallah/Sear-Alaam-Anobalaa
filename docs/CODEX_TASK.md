# الرسالة الجاهزة للنسخ إلى Codex

اقرأ أولًا `AGENTS.md` و`docs/SPEC.md` و`docs/ACCEPTANCE.md`، وافحص `reference/topic_dictionary.csv` و`reference/legacy_indexer.html`.

أريدك أن تنشئ تطبيق ويب عربي متكامل باسم «موسوعة سير أعلام النبلاء». يجب أن يعتمد في النصوص المرجعية على `data/source.mARkdown` من OpenITI، وفي تصنيفات الموضوعات المقترحة على CSV الموجود بالحزمة. لا تعتبر ملف HTML التجريبي قاعدة بيانات ولا تعتبر التصنيف الآلي حقيقة محققة.

أنجز العمل على مراحل في هذا المشروع لا بمجرد اقتراح مخطط:
1. افحص الملفات الموجودة. إذا وجد النص الحقيقي فخذ عيّنة لتفهم العناوين والصفحات؛ وإن لم يوجد فاعمل على محلل للاستيراد وبيانات اختبار اصطناعية فقط، مع إظهار تحذير واضح من غياب المصدر.
2. نفذ قاعدة SQLite وفهرسة FTS5 ومحلل OpenITI متدرجًا مع اختبارات؛ خزّن نص كل ترجمة كما هو، والعناوين والنطاقات والإحالات، وبصمة المصدر.
3. استورد معجم الموضوعات ثم أنشئ نظام ربط موضوع/مقطع بشاهد حرفي ومرحلة تدقيق بشرية. أنشئ صفحة موضوعات، وصفحة أعلام، وقارئ ترجمة كامل، وصفحة لكل شخصية تشمل مواضع ذكرها في الكتاب مع فصلها عن ترجمتها الأصلية.
4. أضف بحثًا عربيًا سريعًا يعرض الأصل حرفيًا مع تطبيع بحث فقط، وتمييز النتائج المرشحة عن المحققة، وعدم خلط شخصين متشابهين في الاسم.
5. أضف واجهة مراجعة لتعديل/اعتماد وسوم الموضوعات ومطابقات الأعلام، ثم اختبارات وأوامر تشغيل موثقة.

أفضل بنية مبدئية FastAPI + SQLite/FTS5 + React/TypeScript/Vite، مع دعم اتجاه RTL كامل. الذكاء الاصطناعي لتصنيف المعاني اختياري ومرحلة لاحقة ولا يجوز له توليد اقتباسات أو إحالات غير موجودة. لا تفترض وجود مفاتيح API أو خدمات مدفوعة.

ابدأ بالتنفيذ الآن. أنشئ README يتضمن أوامر تثبيت المتطلبات وتشغيل الاستيراد وتشغيل الواجهة، واختبر المراحل المتاحة. في النهاية قدم تقريرًا واضحًا بما اكتمل وما يحتاج مراجعة أو النص الأصلي.
